# Koyo — Case Studies

Case studies for Koyo's AI Interviewer and AI Recruiter product.

## Structure

```
koyo-case-studies/
├── README.md
├── skill/
│   └── SKILL.md              ← Cowork skill for generating new case studies
└── case-studies/
    ├── newton-school-da.md                  ← Newton School × Data Analyst hire
    ├── newton-school-bde.md                 ← Newton School × BDE hiring
    ├── physicswallah-academic-counsellor.md ← PhysicsWallah × Academic Counsellor campus drive
    └── reward360-java-engineers.md          ← Reward360 × Java Engineers
```

## How to add a new case study

1. Open Cowork and invoke the `koyo-case-study` skill
2. Provide the brief — company, role, numbers, story
3. The skill will generate the case study, add it to the master Google Doc, and produce an .md file
4. Add the .md file to `case-studies/` and push to this repo
